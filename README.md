# TP5 - Network QoS Monitor

Este repositorio contiene la entrega del Trabajo Práctico N° 5 de la cátedra de Desarrollo de Aplicaciones Móviles.

## Estructura del Repositorio

El proyecto se divide en dos componentes principales:

1. **[NetworkQoSMonitor/](./NetworkQoSMonitor/)**: Contiene el código fuente de la aplicación móvil (React Native CLI puro + Módulos Nativos en Kotlin). **Las instrucciones de compilación y pruebas se encuentran en el [README interno de la App](./NetworkQoSMonitor/README.md).**
2. **[backend/](./backend/)**: Contiene el servidor Node.js/Express de referencia utilizado para el test de Throughput (carga y descarga de paquetes). **Las instrucciones de despliegue y conexión vía túneles se encuentran en el [README del Backend](./backend/README.md).**
