# TP5 - Network QoS Monitor

Este repositorio contiene la entrega del Trabajo Práctico N° 5 de la cátedra de Desarrollo de Aplicaciones Móviles.

## Estructura del Repositorio

El proyecto se divide en dos componentes principales:

1. **[NetworkQoSMonitor/](./NetworkQoSMonitor/)**: Contiene todo el código fuente de la aplicación móvil (React Native + Módulos Nativos en Kotlin). **Toda la documentación técnica requerida, decisiones de arquitectura y detalles de implementación se encuentran en el [README interno de la App](./NetworkQoSMonitor/README.md).**
2. **[backend/](./backend/)**: Contiene el servidor Node.js/Express de referencia utilizado para el test de Throughput (carga y descarga de paquetes).

## Documentación Técnica

Por favor, dirigirse a [NetworkQoSMonitor/README.md](./NetworkQoSMonitor/README.md) para leer la documentación técnica completa exigida en los entregables.
